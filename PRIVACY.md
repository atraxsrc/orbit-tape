# Privacy Policy

Orbit Tape does not include telemetry, analytics, advertising, or user accounts, and does not transfer information to other networked systems unless needed to fetch data from data providers or requested by the user.

Orbit Tape connects to the exchanges enabled in its ticker list (Binance and OKX for a new install; Bybit, Hyperliquid and MEXC can be switched on) and to the exchange behind each open chart. These providers receive the requested data type and identifiers, along with the user's IP address and request metadata. Requests go to a supported provider or to a data server configured by the user, which also receives the optional bearer token. TLS certificates are always verified, except for a user-configured data server when the user turns on "Accept invalid TLS certificates" for it (see [SECURITY.md](SECURITY.md)).

The optional indicator catalog browser contacts only its catalog address, and only when the user opens or refreshes it or installs an indicator; nothing is fetched at startup. The default address is the community catalog at `https://raw.githubusercontent.com/atraxsrc/orbit-tape-indicators/main/catalog.json`, served by GitHub; Settings > Indicator catalog (or `ORBIT_TAPE_CATALOG_URL`) sets another HTTPS address. Requests carry only the User-Agent `orbit-tape/<version>`. The catalog host may log request metadata, including IP addresses, under its own privacy policy. Not opening the browser, or installing content manually, avoids this entirely.

Alerts are shown through the desktop's local notification service. An alert is sent anywhere else only when the user sets up ntfy (Settings > Alerts > Phone) and picks it for that alert, or turns on "Chart alerts to ntfy too": the message (symbol, condition, price and the alert's own text) then goes to the ntfy topic on `https://ntfy.sh` or the server the user entered, which receives the user's IP address and may log it under its own privacy policy. Anyone who knows the topic can read its messages. The alert engine (in the app or `orbit-tape watch`) connects to the exchanges of the saved alerts for live trades and candles. Settings, caches, and logs are stored locally and are not encrypted or uploaded. Proxy credentials and data-server tokens are stored in the system keychain. If a proxy is configured, all application traffic uses it.

Orbit Tape does not control the privacy practices of data providers, data servers, proxies, or the indicator catalog host.
